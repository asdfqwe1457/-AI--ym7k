文献综述与数据分析：AI学术工具的专业用法与风险控制
文献综述：从检索到批判性整合
文献综述不是文献堆砌，而是围绕研究问题，对已有研究进行系统梳理、比较和批判。AI工具可以加速检索、摘要和归类，但不能代替作者阅读原文和形成判断。推荐工具：秘塔AI搜索、知网研学、Zotero、ChatGPT、Claude、Kimi、通义千问、文心一言、智谱清言、Gemini、Grammarly。英文文献还可参考Elicit、Consensus、SciSpace等。

具体流程：用秘塔AI搜索确定关键词和领域地图；用知网研学检索中文核心文献；用Zotero建立文献库并做笔记；用Kimi或Claude上传多篇PDF，要求总结研究问题、方法、样本、结论和局限；用ChatGPT辅助生成综述框架。最后，作者需回到原文核对，避免AI误读或编造。

数据分析：AI辅助代码与统计
理工科和社科研究常涉及数据分析。ChatGPT的代码解释器、Claude、通义千问、智谱清言可辅助编写Python/R代码、解释统计结果、生成图表。但AI不能替代研究设计，也不能保证代码无误。所有分析结果需用原始数据验证，并保留可复现的代码和日志。

对于质性研究，AI可辅助编码、主题归纳和文本分析，但需注意隐私和伦理。上传访谈记录前应脱敏，并遵守知情同意原则。

引用管理：Zotero的核心作用
Zotero是文献管理核心工具，可自动抓取文献信息、生成参考文献、插入引文。配合AI插件，可实现文献摘要和标签。无论使用哪个AI工具，最终引用必须由Zotero或人工核对，确保作者、年份、期刊、页码准确。伪造引用是严重学术不端。

风险控制：幻觉、偏见与数据安全
AI存在幻觉、偏见和时效性问题。风险控制包括：不直接采信AI事实；重要结论交叉验证；引用必须查原文；不上传涉密、隐私或未发表数据；遵守学校AIGC规定。对于英文写作，Grammarly可润色，但术语准确性需人工确认。

结论：AI加速文献与数据环节，作者负责学术判断
文献综述和数据分析是论文创新性的基础。AI工具可以显著提升检索、摘要、编码和统计效率，但不能替代批判性阅读、研究设计和数据真实性。专业工作流是：秘塔/知网研学检索，Zotero管理，Kimi/Claude总结，ChatGPT/通义千问辅助分析，Grammarly润色，人工核对与整合。唯有如此，AI才能成为学术研究的助力，而非风险源。
